Distributionally Robust Model Predictive Control (WDRO-MPC)

Official Mathematical Specification: Convex Quadratic Dual Program with Distance-Governed Speed Regulation
Model Abstract
This document defines the official mathematical program for the Distributionally Robust Model Predictive Control (WDRO-MPC) system governing autonomous longitudinal speed control. By leveraging a nominal reference freezing technique, the controller unifies pedestrian collision avoidance and velocity tracking into a distance-governed reference function $v_{\text{desired}, k}^{(i)}$ that preserves strict quadratic convexity. Robustness against pedestrian behavioral uncertainty is enforced via a Kantorovich dual formulation over a Wasserstein ambiguity ball calibrated with empirical residuals.

1. System Nomenclature & Indices

Meaning of the Mathematical Indices

  • $i \in \{1, 2, \dots, S\}$: Scenario index for historical pedestrian residual vectors $\xi^{(i)}$.
  • $j \in \{1, 2, \dots, S\}$: Paired scenario index representing alternative candidate behaviors evaluated under Wasserstein probability transport.
  • $k \in \{0, 1, \dots, N-1\}$: Discrete time step index within the receding prediction lookahead horizon.
Symbol Physical Interpretation Standard Value Units
$N$ Prediction horizon length $20$ steps
$T_s$ (or $\Delta t$) Control sampling period (5 Hz) $0.2$ $\text{s}$
$S$ Number of empirical behavioral residual scenarios $100$ scenarios
$v_{\max}$ Maximum admissible speed limit $15.0$ $\text{m/s}$
$c$ Distance scaling constant (braking sensitivity threshold) $5.0$ $\text{m}$
$w$ Control acceleration effort weight (passenger comfort) $0.5$ unitless
$\varepsilon$ Wasserstein ambiguity ball radius $0.1$ unitless
$\operatorname{dist}(i,j)$ Pairwise ground metric transportation cost matrix ($M_{i,j}$) Precomputed ($100 \times 100$) unitless
$[a_{\min}, a_{\max}]$ Actuator braking and acceleration limits $[-5.0, +3.0]$ $\text{m/s}^2$

2. Nominal Reference Freezing & Convexification

To prevent non-convex circular dependencies between the vehicle's decision variables and the distance-to-pedestrian calculation, the reference trajectory is parameterized using the Nominal Trajectory Reference Freezing principle.

Step 1: Vehicle Nominal State Projection

At current time $t_0$, given measured position $x_0$ and measured velocity $v_0$, the car's baseline position is frozen along the horizon:

$$x_{\text{frozen}}(k) = x_0 + v_0 \cdot (k \cdot T_s), \quad \forall k \in \{1, \dots, N\}$$

Step 2: Pedestrian Scenario Trajectory Rollout

For each empirical behavioral residual $\xi^{(i)}$ ($i = 1, \dots, S$), the predicted pedestrian position sequence is:

$$\mathbf{p}_{\text{ped}, k}^{(i)} = \mathbf{p}_{\text{nom}}(k) + \boldsymbol{\xi}^{(i)}(k), \quad \forall k \in \{1, \dots, N\}$$

Step 3: Precomputed Encounter Distance $d_k^{(i)}$

The distance between the vehicle and pedestrian at step $k$ under scenario $i$ is evaluated as a static numerical parameter:

$$d_k^{(i)} = \left\| \mathbf{p}_{\text{vehicle, frozen}}(k) - \mathbf{p}_{\text{ped}, k}^{(i)} \right\|_2$$

Step 4: Distance-Governed Desired Speed $v_{\text{desired}, k}^{(i)}$

The target velocity sequence is precomputed prior to optimization:

$$v_{\text{desired},k}^{(i)} = v_{\max} \cdot \frac{d_k^{(i)}}{d_k^{(i)} + c}$$
Convexity Guarantee: Since $x_{\text{frozen}}(k)$ and $\mathbf{p}_{\text{ped}, k}^{(i)}$ are evaluated from measured state feedback, $d_k^{(i)}$ and $v_{\text{desired}, k}^{(i)}$ are pure numerical constants. Consequently, the quadratic tracking loss $(v_k - v_{\text{desired}, k}^{(i)})^2$ is strictly convex with positive definite Hessian.

3. The Official Canonical Optimization Problem

At each control cycle, with current measured speed $v_0$, the optimal longitudinal control sequence is computed by solving the following convex program:

$$\begin{aligned} \min_{\substack{\mathbf{a} \in \mathbb{R}^N, \\ \mathbf{s} \in \mathbb{R}^S, \\ \lambda \ge 0}} \quad & \frac{1}{S} \sum_{i=1}^{S} s_i + \varepsilon \lambda \end{aligned}$$ $$\text{subject to:}$$ $$\begin{aligned} &\textbf{1. Dual Wasserstein Robust Constraints:} \\ & s_i \ge J(a, \xi^{(j)}) - \lambda \cdot \operatorname{dist}(i,j), \quad \forall\, i, j \in \{1, \dots, S\} \\[10pt] &\textbf{where the scenario cost is: } \\ & J(a, \xi^{(j)}) = \sum_{k=0}^{N-1} \left[ \Big(v_k - v_{\text{desired},k}^{(j)}\Big)^2 + w \cdot a_k^2 \right] \\[10pt] &\textbf{2. Vehicle Speed Kinematic Dynamics:} \\ & v_{k+1} = v_k + a_k \cdot T_s, \quad \forall k \in \{0, 1, \dots, N-1\} \\[8pt] &\textbf{3. Actuator Bounds:} \\ & a_{\min} \le a_k \le a_{\max}, \quad \forall k \in \{0, 1, \dots, N-1\} \\[8pt] &\textbf{4. Speed Bounds:} \\ & 0 \le v_k \le v_{\max}, \quad \forall k \in \{0, 1, \dots, N\} \\[8pt] &\textbf{5. Dual Variable Non-Negativity:} \\ & \lambda \ge 0 \end{aligned}$$

4. Theoretical Justification & Receding Horizon Feedback

Error Suppression via Receding Horizon: Although $x_{\text{frozen}}$ assumes constant velocity across the $4.0\text{ s}$ horizon, the controller operates in a closed loop where only the initial command $a_0^*$ is executed for $\Delta t = 0.2\text{ s}$. The open-loop position error introduced during this single sampling step is bounded by: $$\Delta x_{\text{error}} \le \frac{1}{2} |a_{\max}| (\Delta t)^2 = \frac{1}{2} (5.0) (0.2)^2 = 0.10\text{ m}$$ At the subsequent step, fresh sensor measurements $(x_1, v_1)$ initialize a new nominal rollout, continuously suppressing reference drift while preserving millisecond Quadratic Program (QP) solve times.

5. Receding Horizon Execution Law

Let $\mathbf{a}^* = (a_0^*, a_1^*, \dots, a_{N-1}^*)$ denote the optimal acceleration sequence. The control command dispatched to the physical vehicle actuator is:

$$a(t) = a_0^*$$

At $t + T_s$, the horizon recedes, fresh snapshot feedback is measured, and the program is resolved.
